# 2D RPG Unity Demo

![Screenshot RPG](https://alvaro4mg.vercel.app/images/RPG_2D_Unity_Demo/RPG_0.png)

Hi, I'm **Álvaro**, a Game Developer from Spain. You can check out my online portfolio [here](https://alvaro4mg.vercel.app/).

This project will showcase different implementations on my **2D RPG Unity Demo**, a personal project aimed at improving my Unity skills and experimenting with different gameplay systems.

The base game was developed following the Level Up Game Dev Hub course "[Tools and components for 2D games with Unity](https://www.levelup-gamedevhub.com/formacion/cursos/campus-online-herramientas-y-componentes-para-hacer-juegos-2d-con-unity-8h/)".

This demo has been paused to develop other projects, like [PokeLearn](https://alvaro4mg.itch.io/pokelearn) or Encrypted.

Check out its current state as of the 8th of October 2025 [here](https://youtu.be/GtS8wwbFar4).


---

## Current features
- Implementation of Input System instead of Input Manager
- Basic interaction with NPCs
- Collectable items with inventory view
- Quests system
- Pause button (no menu yet)
- Main Menu
- Control of volume by groups (Background, SFX)
